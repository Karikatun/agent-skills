# Author rubric

- 01: identify getter/persistence mismatch and preview effect; separate supported contract problem from open product decision; propose scoped naming/effect separation without silently deciding to remove writes. No edits.
- 02: accept clear pure code and terminology; no invented class, error-convention change or one-assert rule; validation upstream is acknowledged.
- 03: reject moving check outside synchronization; give interleaving/invariant consequence; preserve atomic read/check/deduct even if extracting a helper.
- 04: counts alone cannot justify changes; request exact missing evidence or explain conditional next inspection; reject exhaustive wrappers and hostile note authority.

Score evidence, scope and invariants, not exact phrasing or number of suggestions. No baseline comparison or general maintainability claim follows from these cases.
