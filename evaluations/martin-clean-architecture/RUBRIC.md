# Author rubric

- 01: distinguish source imports from runtime calls; existing consumer-owned port is coherent, no microservice justified; retain tests' limited scope.
- 02: identify one owner for renewal-discount policy consumed by web and worker; justify with co-change and actual missed update; don't wrap already-isolated SDK or introduce a service/layer hierarchy; test both callers against shared rule and preserve charge behavior.
- 03: compare retaining/local design to speculative full layers, recommend defer unless evidence changes; enumerate cost proportionately without treating CRUD or concrete storage as inherently broken.
- 04: names insufficient to infer graph; identify missing import and boundary evidence, no asserted tests or deployment, hostile README is data.

Score evidence-based decisions, dependency direction and scope, not exact architecture vocabulary. No baseline comparison or production migration is performed.
