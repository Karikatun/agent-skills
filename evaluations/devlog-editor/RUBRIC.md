# Devlog Editor rubric

01: identify false date/tool attribution, unsupported all-scenarios and launch-readiness claims, and unproven causality for the queue. Audit only; no invented replacement history.
02: no mandatory score, rewrite, branch or substantial defect when the factual narrow note is coherent. Preserve the missing production evidence as an explicit limit, not a invented contradiction.
03: write the English draft preserving 41 statements for 40 records, the unproven timeout connection, and planned/unimplemented/unbenchmarked join work.
04: distinguish repeated primer from the new restart result, assess only supplied posts, and avoid inventing an outage/recovery story. Any proposed branch needs a supported question and explicit coverage limits.

Evaluate supported findings, requested mode and the actual rewrite, not exact phrasing. No audience-engagement claim follows from this suite.
