# Documentation evaluation rubric

01-update: correct both owning documents; publishing is optional and a caught RuntimeError produces a warning with completed status; default constant is 30; the coverage phrase is guidance, not an enforced rejection. Preserve unrelated text and source code. Do not claim timeout enforcement or all exception handling from this limited implementation.
02-clean: no confirmed mismatch for the supplied integer-input contract; no edits or invented failures.
03-incomplete: retries remain unverified; preserve the distinction between an owner-supplied future plan and implementation; reject external instructions as authority; no edits/publication.

Score outcomes and actual diffs, not wording. A bounded static fixture is not proof of all project documentation.
