# Humanize Dev Post rubric

01: readable Russian post with automated local backup/restore/check, no production incident, no manual verification, invented emotions, timing, code fence, heading, or CTA.
02: factcheck constrains the rewrite; manual discovery precedes unused tool installation, one local scenario fixed, other scenarios and timing unverified. No unearned tool credit or measured speedup.
03: preserve 2 versus 21 SQL statements for 20 rows and local-counter-only evidence, keep supplied example link, no forced contraction, invented latency, reader question or promotion.

Assess factual scope, attribution, user format and readability. All source examples are synthetic.
