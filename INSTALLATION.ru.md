# Установка Agent Skills

[English](INSTALLATION.md) · [Каталог навыков и архивы](README.ru.md)

Установи один навык в любой из 12 агентов ниже. Пути и команды сверены с официальной документацией 10 сентября 2026 года. Установка и выполнение коллекции во всех 12 клиентах не проверялись.

## Установить один выбранный навык

1. В [каталоге коллекции](README.ru.md#скачать-только-выбранный-навык) выбери навык и скачай его ZIP и соответствующий файл `.sha256`. Клонировать весь репозиторий не требуется.
2. Проверь контрольную сумму до распаковки. Например, для API Performance Review 1.0.2 в macOS: `shasum -a 256 -c api-performance-review-1.0.2.zip.sha256`; в Linux: `sha256sum -c api-performance-review-1.0.2.zip.sha256`. В PowerShell выполни `Get-FileHash .\api-performance-review-1.0.2.zip -Algorithm SHA256` и сравни результат с хешем в скачанном `.sha256`. Это проверка целостности, а не личности издателя.
3. Распакуй архив в отдельную папку и прочитай `README.md`, `SKILL.md` и включённые скрипты, если они есть.
4. Выбери личную установку для своих проектов или проектную — для одного репозитория. Скопируй **всю папку навыка**, сохранив имя, `references/`, `scripts/`, `agents/` и `LICENSE`, если они входят в архив, в один каталог из таблицы ниже. Если родительского каталога ещё нет, создай его. Не создавай лишний уровень вложенности.
5. Если одноимённая папка уже существует, сначала сравни версии и сохрани свои изменения вне каталогов обнаружения. Не объединяй старую и новую версии автоматически. Если агент уже обнаруживает этот навык через совместимый каталог, не создавай второй экземпляр.
6. Обнови список навыков или начни новую сессию, затем проверь обнаружение и загрузку по разделу своего агента.

После установки путь имеет вид `<каталог>/api-performance-review/SKILL.md`. В таблице указаны каталоги **без** имени навыка. `~` означает домашний каталог пользователя; в поддерживаемой Windows-версии клиента используй свой профиль пользователя и соответствующую запись пути. Доступность самого клиента на ОС проверяется отдельно.

### Codex: приложение, CLI и расширение IDE

Используй папку из таблицы и начни новую сессию, если клиент не обновил список. Выбери навык через доступный селектор или запроси применение по имени. Вариант с `$skill-installer` уже приведён в README каждого навыка и закреплён на теге версии. Если встроенный установщик сообщил другой поддерживаемый каталог, используй его результат и не добавляй дубликат вручную. Доступность в локальной сессии не подтверждает установку в облачной среде.

### Claude Code

Скопируй папку в один из каталогов Claude Code. В новой сессии вызови `/api-performance-review` с описанием задачи. Личная папка на компьютере не переносится сама в Cowork или облачные сессии; для них документация описывает отдельные источники. В этой инструкции рассматривается локальная установка.

### Cursor

После копирования открой `Customize → Skills` и найди навык. Начни новую сессию, если список не обновился. Cursor также читает `.agents/skills` и совместимые каталоги Claude/Codex, поэтому проверь дубликаты. Синхронизация личной папки `~/.cursor/skills` с Cloud Agents — отдельное действие; `~/.agents/skills` автоматически туда не копируется.

### GitHub Copilot: VS Code и CLI

В VS Code открой `/skills` или `Chat: Open Customizations`, затем проверь раздел Skills. Для явного вызова используй `/api-performance-review`.

В [Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/add-skills) после копирования выполни в чате `/skills reload`, затем `/skills info api-performance-review`. Это команды чата CLI, а не shell. Облачному агенту нужны навыки в его репозитории или среде; личная папка на ноутбуке сама туда не попадает. Другие интеграции Copilot требуют собственной проверки обнаружения.

### Gemini CLI

После копирования выполни в чате `/skills reload` и `/skills list`. Из терминала список можно проверить командой `gemini skills list --all`. Есть встроенная установка из Git или локальной папки, но здесь выбран единый способ через архив одного навыка. Если навык уже есть в `.agents/skills`, не дублируй его: этот совместимый путь имеет приоритет в пределах того же уровня установки.

### Devin Desktop / Windsurf: Cascade

Официальный адрес документации Windsurf перенаправляет на Devin Desktop. Для **Cascade** документация сохраняет каталоги из таблицы. Открой меню настройки Cascade, раздел Skills, и проверь навык; явный вызов — `@api-performance-review`. Devin Local Agent использует отдельный механизм Devin CLI; каталоги Cascade нельзя автоматически считать его инструкцией установки.

### Cline

Открой меню правил/настроек рядом с выбором модели и вкладку Skills. Проверь, что навык найден и включён; найденные навыки включены по умолчанию. Вызови `/api-performance-review` через подсказки чата. Если есть одноимённые личная и проектная копии, Cline отдаёт приоритет личной — не оставляй старую копию незамеченной.

### OpenCode

Начни новую сессию после копирования. Попроси применить навык по имени и проверь вызов инструмента `skill` для нужного навыка. OpenCode также читает `.agents/skills` и `.claude/skills`. Если навык не обнаружен, проверь существующие разрешения: `deny` скрывает навык, а отключённый инструмент `skill` делает навыки недоступными. Не меняй разрешения автоматически ради этой проверки.

### Amp

Для установки только на текущей машине используй `~/.config/agents/skills`. Проверь список командой `amp skills list` в терминале или попроси Amp перечитать навыки. Для проекта используй `.agents/skills`. Это отличается от публикации в личный или командный репозиторий Amp: данный способ ничего туда не загружает.

### Kiro

Можно скопировать папку по таблице или открыть `Agent Steering & Skills → + → Import a skill → Local folder` и выбрать распакованную папку одного навыка. Проверь список и вызови `/api-performance-review`. Для собственного агента CLI проверь, что его `resources` подключают нужные пути `skill://`. Личные каталоги IDE/CLI не объявляются глобальной установкой для Web/Mobile.

### Google Antigravity

Скопируй папку в `~/.gemini/config/skills` или `.agents/skills` проекта и начни новую беседу. Попроси использовать навык по имени; проверь чтение именно его `SKILL.md` и необходимых ссылок. Не подменяй этот путь каталогом Gemini CLI: это разные продукты с разными личными каталогами. Конкретный интерфейс CLI нужно сверять отдельно; здесь описан путь из страницы Skills для редактора.

### Kilo Code

Для текущей платформы используй `.kilo/skills`. После копирования выполни `/reload` в чате или начни новую сессию. Проверь вызов инструмента `skill`. Инструкция относится к текущим CLI/расширению; старые версии расширения могут иметь другую структуру.

## Проверка после установки

Наличие папки — только первый шаг. Проверь, что клиент обнаружил имя, затем что в конкретной задаче он загрузил этот `SKILL.md` и смог открыть включённые ссылки. Текст агента «навык установлен» без записи о загрузке, списка навыков или просмотра источника не считать полной проверкой.

Для первой пробы подходит `api-performance-review`: попроси разобрать небольшой предоставленный обработчик без изменения кода. Установка навыка не предоставляет агенту доступ к отсутствующему репозиторию, сети или инструментам и не отменяет его правила согласования действий.

## Особый случай: Local Video Analysis

Скопировать навык можно тем же способом. Для выполнения его Python-кода отдельно нужны Python, FFmpeg/ffprobe, whisper.cpp, фиксированная модель и yt-dlp для YouTube. Следуй [руководству настройки навыка](https://github.com/Karikatun/agent-skills/blob/local-video-analysis-v1.0.0/skills/local-video-analysis/references/setup.md). Никакие зависимости или модель этим документом не устанавливаются.

Текущая версия проверена на macOS в среде, допускающей запуск нативных инструментов. Linux не проверен, native Windows не поддерживается. В удалённом агенте нужны доступные **в той среде** инструменты, модель и медиа. Поддержка чтения `SKILL.md` сама по себе не доказывает возможность запуска видеоинструмента или просмотра извлечённых кадров.

## Обновить или удалить

Обновляй только выбранный навык после сравнения версии, содержимого и контрольной суммы; сохраняй свои изменения вне сканируемых каталогов. Для удаления убери только выбранную папку и начни новую сессию. Это не удаляет внешние инструменты, модель, результаты работы или ранее сделанные изменения в проектах.
