# Devlog Editor

Version 1.0.0. Review what a technical development post says, why its events connect, and what it adds to a series. It can audit one post, restructure a selected draft, or map supplied posts without inventing history.

```text
Use $devlog-editor to audit this draft against the factual notes and the previous two posts. Do not rewrite it yet.
```

```text
Use $devlog-editor to restructure this post around the confirmed incident. Preserve uncertain attribution and unpublished status.
```

The skill handles facts, causality, chronology, novelty, and technical depth. It does not require a prescribed story formula, a score for every audit, or another skill for a complete response. It can work alongside a style editor, but no companion installation is required. Responses follow the user's language.

This package generalizes a longer private editorial workflow. Product-specific examples, publication links, required companion steps, and rigid output constraints were removed. The series-specific material is loaded only when relevant. No private posts, task history, or unpublished source material are distributed.

Copy this complete folder into a supported skills directory, preserving its reference file and license. Compare an existing copy before replacement. There are no executable scripts, external services, or automatic updates.
