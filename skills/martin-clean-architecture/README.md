# Martin Clean Architecture

Version 1.0.0. Module boundaries, policy ownership and dependency direction evaluated against actual change costs. Use this lens when explicitly requested; it does not automatically govern ordinary implementation or review.

```text
Use $martin-clean-architecture to review this specific change. Explain the observed problem, the smallest useful improvement and its tradeoff. Do not edit yet.
```
